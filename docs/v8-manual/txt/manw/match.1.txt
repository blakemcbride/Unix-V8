NAME
       match - compare style tables from two or more texts

SYNOPSIS
       match [ -flags ][ -ver ] [style-file1 [style-file2 ...]

DESCRIPTION
       Match collates selected variables from tables produced by the style(1)
       command and prints values from the different files one below the other
       for easy comparison.  The style-files must contain tables produced by
       style.

       Match can also run on one file to produce an abbreviated version of the
       style table.

       When comparing texts, it is advisable to use texts of similar length.

       Two options give information about the program:

            -flags print the command synopsis line (see above) showing command
                   flags and options, then exit.

            -ver   print the Writer's Workbench version number of the command,
                   then exit.

USES
       This program is useful for visually inspecting similarities and
       differences among stylistic features of different documents or drafts
       and their revisions.

SEE ALSO
       style(1), prose(1).
