NAME
       sum - sum and count blocks in a file

SYNOPSIS
       sum [ file ] ...

DESCRIPTION
       Sum calculates and prints a 16-bit checksum along with the length (in
       blocks) and name of each file.  If no files are given, the standard
       input is summed.  If file is `-', file names are read from standard
       input.

       Sum is typically used to look for bad spots, or to validate a file
       communicated over some transmission line.

SEE ALSO
       wc(1).

DIAGNOSTICS
       `Read error' is indistinguishable from end of file on most devices;
       check the byte count.
