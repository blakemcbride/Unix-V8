NAME
       basic, bas, bite - Basic language interpreters

SYNOPSIS
       /usr/bin/lcl/basic

       /usr/bin/lcl/bas

       /usr/bin/lcl/bite

DESCRIPTION
       Of these three completely different Basic interpreters, basic is the
       biggest, and unfortunately the best.  Caveat emptor.
