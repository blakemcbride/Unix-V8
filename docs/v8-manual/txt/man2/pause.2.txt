NAME
       pause - stop until signal

SYNOPSIS
       pause()

DESCRIPTION
       Pause never returns normally.  It is used to give up control while
       waiting for a signal from kill(2) or alarm(2).  Upon termination of a
       signal handler started during a pause, the pause call will return.

SEE ALSO
       kill(1), kill(2), alarm(2), signal(2), setjmp(3)
