NAME
       renice - alter priority of running process by changing nice

SYNOPSIS
       /etc/renice [ -pri ] pid ...

DESCRIPTION
       Renice alters the priority of the process with process-id pid.  The
       default pri is 19.  Changing the priority requires permission to write
       /proc/pid (see proc(4)), so only the super-user can alter an arbitrary
       process's priority.  Only the super-user can raise a process's
       priority.

FILES
       /proc/pid

SEE ALSO
       nice(1), nice(2), proc(4)
