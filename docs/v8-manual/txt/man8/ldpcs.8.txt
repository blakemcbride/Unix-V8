NAME
       ldpcs - load comet microcode

SYNOPSIS
       /etc/ldpcs [ -f ] [ -v ] pcsfile

DESCRIPTION
       Ldpcs loads microcode from pcsfile into the VAX-11/750 patchable
       control store.  Normally, the system ID is checked to see that the
       system is a 750 and that its base microcode revision level is
       appropriately high; the -f option removes the checks.  The -v option
       causes the microcode version number to be printed after loading.

       Ldpcs is conventionally invoked from /etc/rc to load the most recent
       DEC microcode patches from /etc/pcs750.bin.

FILES
       /dev/mem
       /dev/mtpr

BUGS
       Calling ldpcs is a good idea, but it is not mandatory; the system will
       run without the patches.
