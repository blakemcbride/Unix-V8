TTYNAME(3)                 Library Functions Manual                 TTYNAME(3)

NAME
       ttyname, cttyname, isatty, ttyslot - find name of a terminal

SYNOPSIS
       char *ttyname(fildes)

       char *cttyname()

       isatty(fildes)

       ttyslot()

DESCRIPTION
       Ttyname returns a pointer to the null-terminated path name of the
       terminal device associated with file descriptor fildes.

       Cttyname returns a pointer to the path name of the terminal device
       associated with the first file descriptor among 0,1,2 that is connected
       to a terminal device.  This probably is the control terminal for the
       present process.

       Isatty returns 1 if fildes is associated with a terminal device, 0
       otherwise.

       Ttyslot returns the number of the entry in the ttys(5) file for the
       control terminal of the current process.

FILES
       /dev/∗
       /etc/ttys

SEE ALSO
       ioctl(2), ttys(5)

DIAGNOSTICS
       Ttyname returns a null pointer (0) if fildes does not describe a
       terminal device in directory `/dev'.

       Ttyslot returns 0 if `/etc/ttys' is inaccessible or if it cannot
       determine the control terminal.

BUGS
       The return value points to static data whose content is overwritten by
       each call.
