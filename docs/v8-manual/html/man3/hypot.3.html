HYPOT(3M)                                                            HYPOT(3M)

NAME
       hypot, cabs - euclidean distance

SYNOPSIS
       #include <math.h>

       double hypot(x, y)
       double x, y;

       double cabs(z)
       struct { double x, y; } z;

DESCRIPTION
       Hypot and cabs return

              sqrt(x∗x + y∗y),

       taking precautions against unwarranted overflows.

SEE ALSO
       exp(3) for sqrt
