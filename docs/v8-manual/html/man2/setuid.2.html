SETUID(2)                     System Calls Manual                    SETUID(2)

NAME
       setuid, setgid - set user and group ID

SYNOPSIS
       setuid(uid)

       setgid(gid)

DESCRIPTION
       The user ID (group ID) of the current process is set to the argument.
       Both the effective and the real ID are set.  These calls are only
       permitted to the super-user or if the argument is the real or effective
       ID.

SEE ALSO
       getuid(2)

DIAGNOSTICS
       Zero is returned if the user (group) ID is set; -1 is returned
       otherwise.
