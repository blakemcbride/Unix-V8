SERVER(1)                   General Commands Manual                  SERVER(1)

NAME
       server - run anonymous command on another machine

SYNOPSIS
       server machine command

DESCRIPTION
       Server uses Datakit to run command on the named machine.  If it has
       set-uid mode, the owner of server will log in on the remote machine.
       In this way, a user can execute commands on the remote machine without
       having a login there.

       Server typically accepts only a small set of commands, such as who, ps,
       cat, and date; the list is at the discretion of the remote machine.
       Server also checks for suspicious argument characters.

FILES
       /etc/server    list of legal commands

SEE ALSO
