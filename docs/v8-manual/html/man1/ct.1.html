NAME
       ct - call terminal (and start a session)

SYNOPSIS
       ct [-c count ] [-w interval ] [-h] phone-number [ service-class ]

DESCRIPTION
       Ct places a telephone call to a remote terminal and allows a user to
       log in on that terminal in the normal fashion.  The terminal must be
       equipped with an auto-answer modem.

       The phone number and service class are interpreted the same way as by
       cu(1).  If ct cannot reach the number given, it tries again the number
       of times given by count (default 5), waiting each time for a given
       interval (default 60 seconds).

       If the -h option is given, ct tries to hang up the phone before placing
       the call.  This is useful for a ``call me right back'' type of
       arrangement.
