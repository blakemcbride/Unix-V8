TTY(1)                      General Commands Manual                     TTY(1)

NAME
       tty - get terminal name

SYNOPSIS
       tty

DESCRIPTION
       Tty prints the pathname of the user's terminal.

DIAGNOSTICS
       `not a tty' if the standard input file is not a terminal.
