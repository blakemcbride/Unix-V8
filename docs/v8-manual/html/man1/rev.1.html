NAME
       rev, revpag - reverse lines or pages

SYNOPSIS
       rev [ file ] ...

       revpag [ option ] ... [ file ] ...

DESCRIPTION
       Rev copies the standard input or the named files to the standard
       output, reversing the order of characters in every line.

       Revpag copies the standard input or the named files to the standard
       output, reversing the order of the pages.  (The name `-' means the
       standard input.)  Options define what constitutes a `page':
