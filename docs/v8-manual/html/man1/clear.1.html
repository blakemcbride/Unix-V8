CLEAR(1)                    General Commands Manual                   CLEAR(1)

NAME
       clear - clear terminal screen

SYNOPSIS
       clear

DESCRIPTION
       Clear clears the screen of the terminal on its standard output.  It
       depends upon the environment variable TERM to know how to do it.

FILES
       /etc/termcap

SEE ALSO
       term(7)
