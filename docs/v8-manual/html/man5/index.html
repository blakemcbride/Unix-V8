Section 5: File formats and conventions

a.out.5a.out - assembler and link editor output
acct.5acct - execution accounting file
ar.5ar - archive (library) file format
config.5config - system configuration template files
core.5core - format of memory image file
cpio.5cpio - format of cpio archive
dir.5dir - format of directories
environ.5environ - user environment
filsys.5filsys, flblk, ino - format of file system volume
fstab.5fstab - static information about the filesystems
group.5group - group file
map.5map - digitized map formats
mtab.5mtab - mounted file system table
news.5news - USENET network news article, utility files
newsrc.5newsrc - information file for readnews
passwd.5passwd - password file
plot.5plot - graphics interface
stab.5stab - symbol table types
termcap.5termcap - terminal capability data base
ttys.5ttys - terminal initialization data
types.5types - primitive system data types
utmp.5utmp, wtmp - login records
view2d.5view2d - movie of a function f(x, y, t)
whoami.5whoami - computer name
