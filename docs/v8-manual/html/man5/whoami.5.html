WHOAMI(5)                     File Formats Manual                    WHOAMI(5)

NAME
       whoami - computer name

SYNOPSIS
       cat /etc/whoami

DESCRIPTION
       The file /etc/whoami contains one line of information - the name of the
       computer, as used in mail, rx, or uucp(1).
